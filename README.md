## Основной проект

### JARVIS VPN

Коммерческий VPN-сервис, в котором Telegram используется как основной пользовательский интерфейс.

- ведущий разработчик проекта;
- полный цикл работы: от постановки задачи и реализации до ручного релиза и пострелизного мониторинга;
- Python, Telegram Bot API, PostgreSQL, REST API, webhooks, Linux;
- около 500 пользователей за всё время и около 120 активных платных подписчиков по состоянию на сентябрь 2026 года;
- коммерческий исходный код и инфраструктурные данные не публикуются.
